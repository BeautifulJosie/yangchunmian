# Travel Book Template

把自己的旅行计划做成一份随身带着走的单文件网页——手机打开就能看，不用装 App，也不用连数据库。

这是一份 **AI-Friendly 的轻量旅行网页模板**。把 `travel-book` 这个文件夹和自己的旅行资料（航班、酒店、每日安排、
门票等）一起交给支持文件读写的 AI（Claude Code、Cursor 之类都可以），它会照着 `SKILL.md` 里的
规范，把 `template/index.html` 改写成这次旅行专属的页面。

> 目标是先快速拿到一版完整可用的网页，之后旅行进行中随时让 AI 继续改（订好了、改地方了、
> 这天过去了……）。

---

## 页面长什么样

- Hero 区：标题、日期人数、机票/酒店/门票状态一眼看
- **NOW 卡片**：自动倒计时到下一个行程事件，整趟旅行全自动推进，不用手动切
- 行程总览：一张简单路线图
- 航班卡片
- **每日行程卡**：可折叠、点地名跳 Google 导航、点 ⓘ 展开地点简介、点按钮展开当天完整路线地图
- 待办清单：打勾状态记本地，已确认的事项自动显示完成；也可以选配免费的 Supabase，
  变成不同朋友打开同一个链接、互相添加/编辑/勾选、实时同步的共享清单
- 贴士

`template/index.html` 打开就是一份能运行的示例（日本关西六日的假数据），四种交互都能直接点着玩，
照着改成自己的行程就行。

## 怎么用

最省事的方法：打开你自己的 AI（Claude Code、Cursor、Codex 这类能读写文件、能联网的都可以），把下面这段话整段复制发给它，同时把旅行资料一起发过去：

```text
请用这个模板帮我做一份旅行手册网页：
https://github.com/BeautifulJosie/yangchunmian/tree/main/travel-book

1. 先把这个文件夹完整下载到我电脑上一个新文件夹里，比如运行
   npx degit BeautifulJosie/yangchunmian/travel-book my-travel-book
   如果用不了这条命令，可以用 git 稀疏检出，或者逐个下载里面的文件。
2. 读里面的 SKILL.md，严格按它的步骤来：先跟我确认资料和缺口，再改 template/index.html。
3. 做完告诉我生成的文件在哪、怎么打开。
```

AI 会自己下载模板、读规范、问你缺的信息，再动手生成页面。资料越完整，第一版就越接近能直接用。

如果你用的 AI 不能联网或不能操作文件：点仓库首页的「下载这个文件夹」，解压后把整个文件夹和旅行资料一起交给它，告诉它“请照着这个文件夹里的 SKILL.md 帮我生成一份旅行页面”。

## 本地预览

不需要装任何东西，`template/index.html` 直接用浏览器打开就能看；或者在项目目录起一个本地服务器：

```bash
npx serve .
```

## 发布分享

做完后 AI 会主动问你要不要发布成一个公网链接，发给同行的人不用登录、不用注册就能直接打开：

- **用腾讯 WorkBuddy**：它自带网页托管，直接帮你发布，不需要别的账号。
- **用其他 AI**（Claude、ChatGPT、Claude Code、Cursor、Codex 等）：需要你先注册一个免费的
  [Cloudflare](https://dash.cloudflare.com/sign-up) 账号，剩下的 AI 会一步步带你做完，
  能运行命令的 AI 会直接帮你部署。
- 不想发布也可以，把生成的 HTML 文件直接发给同行的人，手机打开就能看。

具体流程见 `SKILL.md` 第 5 节。

## 数据与隐私

旅行资料会直接写进 `template/index.html`，只存在你自己的仓库/浏览器里，没有后端、没有数据库。

如果之后要发布出去分享链接：

- **机票/酒店确认号不要写在页面里**——公开链接谁都能看到，很多航司只凭确认号+姓氏就能改签。
- 酒店地址、门锁密码这类信息要不要保留，自己根据分享范围决定。
- 待办清单默认的打勾状态存在浏览器 `localStorage`，只在当前设备生效，换设备/换浏览器不同步；
  开启了 `optional/supabase-sync/` 之后，待办数据会存在你自己的 Supabase 项目里，
  同一个 `tripId` 下的人默认互相可读写，具体权限见该目录的 `schema.sql`。

## 关于待办同步

默认待办清单是纯本地的，谁打开页面都是自己单独一份。

如果想要"发出去的链接，不同朋友打开都能一起加待办、互相看到对方勾选/编辑"的效果，
按 `optional/supabase-sync/README.md` 配一个免费的 Supabase 项目，改三行配置就能开启，
不需要自己写后端。不配置就保持现在的纯本地行为，互不影响。

## 关于地图

模板里默认放的是一段几个点连线的简易路线示意图，大多数行程这样就够用。

如果想要更精细的路线/轮廓地图，`SKILL.md` 第 3 节有画法说明（等距投影 + Python 脚本批量算坐标），
比较耗时间，简单行程可以跳过。
