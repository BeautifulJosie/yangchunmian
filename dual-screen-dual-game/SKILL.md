# 双屏双游戏

一台电脑、两块屏、两个游戏同时跑：**主屏游戏**用键鼠（通常在前台），**副屏游戏**用手柄（通常在后台）。
原理和踩坑细节见 [references/background.md](references/background.md)。

## 红线（任何时候都不能违反）

1. **带反作弊的游戏绝不装 Special K。** `Install-SpecialK.ps1` 检测到 EasyAntiCheat、BattlEye、Vanguard 等会直接拒绝——不要绕过它，也不要手动把 dll 复制进这类游戏目录（英雄联盟、无畏契约、Apex、原神等），会被当成外挂封号。带反作弊的游戏应该放主屏、用键鼠，它本来就在前台，不需要 Special K。
2. **改系统设置前先说明、得到同意**：显示器分辨率/刷新率/排列、默认播放设备、设备静音、游戏模式、往游戏目录放文件。
3. **用户问哪个游戏，就只动哪个游戏。** 修 A 游戏的声音时，不要顺手改 B 游戏的输出设备——用户可能有意让 B 跟着耳机走。
4. **游戏配置文件只在游戏退出后改**（游戏和 Special K 退出时都会重写自己的配置，运行中改了会被覆盖）。改之前备份；`Install-SpecialK.ps1` 会自动备份 `dxgi.ini`。
5. **不要写"后台等游戏退出再改"的守护脚本**——电脑一重启它就没了，改动根本不会发生。请用户退出游戏，你改完后自己启动游戏验证。
6. **不要强制结束游戏进程**，除非游戏已经卡死并且用户同意（会丢未保存的进度）。
7. **放 dll 被你的安全策略拦截时，不要想办法绕过。** 用 `-SkipDll`，脚本会打开两个文件夹，请用户自己拖进去改名。

## 脚本

所有脚本都在 `scripts\`，用 Windows PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\<脚本名>.ps1 <参数>
```

| 脚本 | 作用 | 会不会改东西 |
|---|---|---|
| `Diagnose.ps1` | 体检：显示器（序号、分辨率、刷新率、位置）、声音设备（默认、静音、谁在出声）、正在运行的游戏（路径、窗口在哪块屏、Special K 是否加载）、显卡占用、游戏模式 | 只读 |
| `Install-SpecialK.ps1` | 给副屏游戏装 Special K 并写好配置；`-DryRun` 试运行，`-SkipDll` 只写配置，`-Uninstall` 卸载 | 改游戏目录 |
| `Set-AppAudioDevice.ps1` | 把某个程序的声音固定到指定设备；`-Clear` 取消固定；`-List` 列出设备和各程序当前去向 | 改该程序的输出设备 |
| `Get-AudioDevices.ps1` | 每个播放设备的音量、静音、谁正在出声；`-Unmute` 解除所有设备静音 | 加 `-Unmute` 才改 |
| `Move-WindowToMonitor.ps1` | 把游戏窗口挪到指定屏幕铺满（一次性，游戏不会记住） | 只挪窗口 |

## 流程

### 0. 先问清楚

用户多半不懂技术，用大白话问，一次问完：

- 哪个游戏放哪块屏？哪个用键鼠、哪个用手柄？
- 声音想从哪出：两个游戏各走哪个设备（音响 / 电视或显示器喇叭 / 耳机）？有没有哪个游戏希望"戴上耳机就自动从耳机出"（这种就不要给它固定设备）？
- 现在具体遇到什么问题？（后台没声、按键失灵、卡、开错屏……）

然后请用户**把两个游戏都启动起来**，诊断和声音设置都需要游戏在运行。

### 1. 体检（只读）

```powershell
scripts\Diagnose.ps1
```

记下：副屏的**显示器序号**、副屏游戏的**进程名和目录**、两块屏的分辨率差异、有没有设备处于静音、默认设备是哪个、显卡占用。把发现的问题用三五行告诉用户。

### 2. 副屏游戏装 Special K（解决：后台没声 + 手柄按键失灵）

先试运行，把会做的事讲给用户：

```powershell
scripts\Install-SpecialK.ps1 -Process <副屏游戏进程名> -Monitor <副屏序号> -DryRun
```

用户同意后去掉 `-DryRun` 正式执行（被安全策略拦截就加 `-SkipDll`）。

- 只适用于 DX11 / DX12 游戏（绝大多数新游戏）。脚本拒绝时把原因如实告诉用户，不要硬装。
- 默认锁 60 帧（适合 60Hz 电视）。副屏是高刷显示器就用 `-TargetFps 120` 之类，`0` 表示不限。
- 游戏正在运行且 Special K 已加载时，脚本会要求先退出游戏（否则配置会被覆盖）。

然后告诉用户需要**他自己点**的几处（说清楚菜单路径）：

1. 游戏内显示模式设为「**无边框窗口**」。不要用独占全屏：它会让 HDMI 重新握手，电视的声音设备会断一下，Windows 就把默认播放设备换走。
2. Steam 游戏：Steam → 库 → 右键游戏 → 属性 → 控制器 → 「**禁用 Steam 输入**」。不关的话，一切到主屏游戏，手柄就整个被 Steam 截走。
3. 游戏里如果有「未聚焦时音量 / 后台音量」，拉到 100（双保险）。
4. 重启游戏，第一次启动弹出 Special K 许可协议时接受。

### 3. 声音分开（按用户意愿）

最简单是让用户自己在 **设置 → 系统 → 声音 → 音量合成器** 里给每个游戏选「输出设备」，可视化、随时能改。要你代劳就用脚本：

```powershell
scripts\Set-AppAudioDevice.ps1 -List
scripts\Set-AppAudioDevice.ps1 -Process <进程名> -Device <设备名里的一段>
scripts\Set-AppAudioDevice.ps1 -Process <进程名> -Clear      # 改回跟随系统默认
```

- 程序要正在出声才能设，脚本会等（默认 60 秒），请用户让游戏发出点声音。
- 设置按 exe 记住，以后自动沿用。
- 英雄联盟有两套进程：客户端 `LeagueClientUxRender`（多个，脚本会全部处理）和对局 `League of Legends`（进了对局才有），需要分别设置。
- 只设用户要求的那个游戏（红线 3）。

### 4. 性能（副屏游戏卡顿时才做）

两个游戏共用一张显卡。按顺序给建议，每条先征得同意：

1. 主屏游戏的帧率上限设到显示器刷新率（游戏内设置），别开"无上限"。
2. 副屏桌面分辨率降到和主屏一样（比如 4K 电视 → 2560×1440 @ 60Hz，设置 → 系统 → 屏幕 → 选中副屏）。电视自己会放大，坐远看差别很小，渲染量减半以上；还顺带解决了"虚幻引擎游戏只占副屏一部分"。
3. 关闭游戏模式（设置 → 游戏 → 游戏模式）：它会偏袒前台游戏，后台那个就被压帧了。
4. 副屏游戏画质 / DLSS 档位降一档；**关掉 DLSS 帧生成**，分辨率一变它就可能让游戏卡死。

改完用 `Diagnose.ps1` 对比显卡占用。作者的电脑（RTX 4060 Ti 8GB）：电视 4K 渲染时占用 99%，降到 1440p 后约 40%。

### 5. 验证

两个游戏都开着、**焦点放在主屏游戏上**，跑 `Diagnose.ps1`，确认：

- 副屏游戏窗口在副屏、铺满，Special K 显示「已加载」
- 两个游戏分别在预期的设备上「正在出声」
- 没有设备处于静音

再请用户实际试一下：焦点在主屏游戏时，按手柄 A 键、听两边的声音。

### 6. 撤销

- Special K：`scripts\Install-SpecialK.ps1 -GameDir <游戏目录> -Uninstall`（只删 `dxgi.dll`）
- 声音固定：`scripts\Set-AppAudioDevice.ps1 -Process <进程名> -Clear`，或者在音量合成器里选「默认」
- Steam 输入、显示设置：请用户在原处改回

## 排错

| 现象 | 先查什么 | 怎么办 |
|---|---|---|
| 后台还是没声 | `Diagnose.ps1` 看 Special K 是否已加载 | 没加载：确认 `dxgi.dll` 在游戏 exe 同目录、游戏是 DX11/12；已加载：把游戏内"后台音量"拉到 100 |
| 手柄在后台完全不动 | Steam 输入 | 给这个游戏禁用 Steam 输入 |
| 只有 A / View 等确认键失灵 | Special K 是否加载 | 同"后台还是没声" |
| 突然完全没声 | `Get-AudioDevices.ps1` | 设备被静音 → 征得同意后 `-Unmute`（Parsec 的「连接时静音主机扬声器」`server_admin_mute` 会留下静音，可以建议关掉）；默认设备变了（连了蓝牙耳机）→ 问用户想要哪个；固定输出被清掉 → 重新 `Set-AppAudioDevice` |
| 声音跑到耳机 / 别的设备 | `Set-AppAudioDevice.ps1 -List` | 该游戏显示"跟随系统默认"就重新固定 |
| 游戏开在主屏 | 显示器排列是否变过（`Diagnose.ps1` 看位置） | 游戏退出后 `Install-SpecialK.ps1 -GameDir <目录> -Monitor <序号>` 重新写首选显示器；临时救急 `Move-WindowToMonitor.ps1 -Process <进程名> -Secondary` |
| 游戏只占副屏一部分 | 副屏分辨率是否高于主屏 | Special K 的 `Fullscreen=true` 会撑满；或者把副屏分辨率设成和主屏一样 |
| 游戏卡住不动、没声 | 游戏目录 `logs\dxgi.log` 是否一直在刷 `DLSS Frame Generation ... Failed` | 副屏分辨率中途变了。征得同意后结束游戏，把分辨率改回去，并关掉帧生成 |
| 主屏游戏被锁 60 帧 | 主屏刷新率（`Diagnose.ps1`） | 刷新率掉回了 60Hz，请用户在设置里改回 |
| `Set-AppAudioDevice.ps1` 报 hr 错误 | Windows 版本 | 这个未公开接口在不同版本上可能不一样，改用音量合成器手动设置 |
| 只检测到一块屏 | 电视/副屏是否开机、信号源是否对 | 开机后重跑 |
