# 双屏双游戏

让一台 Windows 电脑在两块屏幕上同时玩两个游戏：一个用键鼠，一个用手柄。两个游戏都能出声，手柄在后台也好用，声音还能分到不同设备，比如一个走音响、一个走电视。不用懂代码。

> v0.1：在作者自己的电脑上验证过（Windows 11 + 英雄联盟 + 光与影：33 号远征队）。换了别的游戏组合，欢迎反馈效果。

## 怎么用

**不用自己下载。** 先把两个游戏都打开，然后在电脑上打开你自己的 AI（Claude Code、Codex 这类能读写文件、能运行命令、能联网的都可以），把下面这段话整段复制发给它：

```text
我想在两块屏幕上同时玩两个游戏，请用这个项目帮我配置好：
https://github.com/BeautifulJosie/yangchunmian/tree/main/dual-screen-dual-game

1. 先把这个文件夹完整下载到我电脑上，比如运行
   npx degit BeautifulJosie/yangchunmian/dual-screen-dual-game dual-screen-dual-game
   如果用不了这条命令，可以用 git 稀疏检出，或者下载整个仓库的 ZIP 只取这个文件夹。
2. 读里面的 SKILL.md，严格按它的步骤来：先问清楚我哪个游戏放哪块屏、声音想从哪出；
   改系统设置和游戏文件之前先告诉我，我同意了再动手。
3. 需要我在游戏里或 Steam 里点的地方，告诉我具体点哪里。
```

接下来 AI 会：

1. 下载这个项目，给你的电脑做个体检：两块屏、声音设备、两个游戏各开在哪。
2. 问你：哪个游戏放哪块屏，两个游戏的声音各想从哪出。
3. 给副屏（用手柄）那个游戏装上开源工具 Special K，让它在后台也照常出声、手柄所有按键都能用。
4. 按你的意思把两个游戏的声音分开。
5. 请你在游戏和 Steam 里点几个设置（AI 会告诉你点哪里），然后一起验证效果。

如果你用的 AI 不能联网或不能操作文件：点仓库首页的「下载这个文件夹」，解压后把整个文件夹交给它，告诉它“请照着这个文件夹里的 SKILL.md 帮我配置双屏双游戏”。

**遇到任何问题都直接问你的 AI。** 截个图发给它，让它照着 SKILL.md 里的排错表帮你查。

## 直接把屏幕和手柄接上，会遇到什么

| 问题 | 原因 | 这个项目怎么解决 |
|---|---|---|
| 副屏游戏一放到后台就没声音 | Windows 同一时间只有一个前台窗口，游戏一到后台就自己静音 | 用 Special K 让游戏以为自己一直在前台 |
| 手柄 A 键、确认键按了没反应（摇杆正常） | 游戏在后台时会忽略手柄的界面按键 | 同上 |
| 一切到另一个游戏，手柄就整个不动 | Steam 输入按前台窗口分配手柄 | 给这个游戏关掉 Steam 输入 |
| 两个游戏的声音混在一起 | 都从默认设备出声 | 给每个游戏指定输出设备 |
| 副屏游戏只占屏幕一部分 | 很多游戏按主屏的分辨率开窗口 | 让游戏铺满副屏，或者把副屏分辨率调成和主屏一样 |
| 副屏游戏卡顿 | 两个游戏抢一张显卡 | 降副屏分辨率、锁帧、关游戏模式 |
| 游戏总开在主屏 | 游戏记的是旧的窗口位置 | 按显示器硬件固定首选屏幕 |

## 适合谁

一个游戏在排队、挂机或等待，另一个游戏在打。比如英雄联盟排队时在电视上推单机剧情，回合制游戏放副屏慢慢玩，主屏照常打网游。

前提只有一个：**一个游戏用键鼠，一个用手柄**，输入设备互不抢。

## 放心用

- **改什么都先问你。** 改系统设置、往游戏目录里放文件之前，AI 会先说要做什么，你同意了才动手。
- **不碰网游。** 检测到反作弊（英雄联盟、无畏契约等）会直接拒绝安装 Special K，不让你担封号风险。Special K 只装给单机游戏；带反作弊的网游放主屏用键鼠玩，它本来就不需要。
- **随时能撤销。** 删掉游戏目录里的 `dxgi.dll` 就恢复原样；声音分流在音量合成器里改回「默认」就行。
- 所有操作都在你自己的电脑上完成，不上传任何东西。

直接跟 AI 说就行，比如：

- 「英雄联盟跟着耳机走，戴上耳机就从耳机出」

- 「电视上的游戏有点卡，帮我看看」

## 常见问题

**我玩的不是这两个游戏，能用吗？**
可以。副屏那个游戏是单机、DX11 或 DX12（绝大多数新游戏都是）就行；主屏那个随便，用键鼠玩就好。

**突然又没声了？**
跟 AI 说「游戏没声了，帮我查一下」。最常见的是设备被静音了（音量显示 100%，但静音开关开着），或者连上蓝牙耳机后声音跟着跑过去了。AI 会帮你查出来。

**Mac 能用吗？**
不能，只支持 Windows 10 / 11。

## 给会用命令行的人

脚本都在 `scripts\`，用 Windows PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\Diagnose.ps1      # 只读体检
```

| 脚本 | 作用 |
|---|---|
| `Diagnose.ps1` | 体检：显示器、声音设备、正在运行的游戏、显卡占用、游戏模式（只读） |
| `Install-SpecialK.ps1` | 给副屏游戏装 Special K 并写好配置：`-Process <进程名> -Monitor <序号>`；`-DryRun` 试运行，`-SkipDll` 只写配置，`-Uninstall` 卸载 |
| `Set-AppAudioDevice.ps1` | 程序声音固定到某个设备：`-Process <进程名> -Device <设备名一段>`；`-Clear` 取消，`-List` 查看 |
| `Get-AudioDevices.ps1` | 各设备音量、静音、谁在出声；`-Unmute` 一键解除静音 |
| `Move-WindowToMonitor.ps1` | 把游戏窗口挪到指定屏幕：`-Process <进程名> -Secondary` |

手动安装 Special K：从 [Special K Releases](https://github.com/SpecialKO/SpecialK/releases) 下载 `SpecialK.7z`，把 `SpecialK64.dll` 复制到游戏 exe 所在目录并改名为 `dxgi.dll`，再把 [`specialk/dxgi.ini`](specialk/dxgi.ini) 放到同一个目录。各项配置的含义见 [references/background.md](references/background.md)。

## 这个项目怎么来的

作者在一台电脑上同时玩英雄联盟和光与影：33 号远征队，把遇到的现象用大白话告诉 Claude Code，比如「远征队放后台就没声，手柄 A 键也不好使」「能不能让英雄联盟走音响、远征队走电视」「电视上的远征队掉帧很严重」。它自己读游戏配置、音频设备和日志，找到原因，再下载工具、写配置、写脚本、验证。这个项目就是把这套过程整理出来，让你的 AI 也能照着做一遍。
