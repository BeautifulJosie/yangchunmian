# 小红书视频封面生成指南

这份 SKILL.md 和 `template/` 里的三个模板配套使用。目标是：每张新封面一眼就能认出是同一个系列，只换标题、主题和中间的示意画面。**改的是内容，不是骨架。**

## 安装好之后：尽量少让用户操作

用这个 Skill 的大多是不懂技术的普通用户：

- 能自己运行的命令就自己运行，不要让用户去终端里操作。
- 遇到问题、自己解决不了时，用大白话告诉用户，给一个简单的手动办法。
- 安装完成后，在同一个对话里接着往下走。示例开场白：
  > 封面工具装好啦！告诉我这期视频讲什么、想用什么大标题，有截图也可以直接发我。

## 0. 开始前，先问清楚这几件事

缺什么问什么，一次只问一个问题；能从对话里推断出来的直接用，不要重复问。

- **大标题**：视频的核心卖点，2 行。
- **副标题**：一句话。
- **主题名**：1 个或 2 个，比如「周末洛杉矶一日游」「国庆家长的桂林行程」。
- **用了什么工具**：用户说是哪个工具做的就写哪个，不要擅自加别的工具名。
- **中间画什么**：网页、App 界面、对话、地图等。用户有截图就照着截图画。

用户发来小红书链接时，先试着打开；打不开就直接请用户用一两句话描述视频内容。

## 1. 选模板

| 情况 | 模板 | 示例图 |
| --- | --- | --- |
| 两个案例对比 | `template/two-cases.html` | `examples/two-cases.png` |
| 一个主题 | `template/single-topic.html` | `examples/single-topic.png` |
| 工具/App 演示（翻译、对话、拍照讲解） | `template/tool-demo.html` | `examples/tool-demo.png` |

把选中的模板**复制一份**到 `output/` 下再改（例如 `output/2026-10-豆包.html`），不要直接改模板。改之前先完整读一遍模板。

## 2. 风格规范（固定，不要改）

**画布**
- 尺寸 1080×1440（3:4）。
- 根元素是 `<div id="cover">`，设置 `overflow: hidden`。

**配色**
- 背景 `#E3EAED`，上面有浅色等高线纹理（`#C9D6DB`）。
- 正文用黑 `#101A20`，次要文字用深青 `#1F4F5E`。
- 主色 `--accent` 默认 `#2C6E80`（青蓝），用在竖条、副标题、括号、`&`、斜色带和第二个标签上。
- 主题需要时可以换主色（例：德州用 `#B5541E` 橙），但一张图只用一个主色。
- 深色卡片 `#16222B`，打卡绿 `#3D7A4D`，高亮黄 `#E3A320`。

**字体**
- 用思源黑体 / Noto Sans CJK SC，Mac 上自动回退到苹方。
- 标题用 900 字重。

**标题区（左上）**
- 左边一根 10px 宽的主色竖条，右边是大标题。
- 大标题固定 2 行，字号 100–116px，设 `white-space: nowrap`。
- 每行最多约 8 个汉字。放不下就缩小字号或改写，**绝不能出现单个字掉到下一行**。
- 副标题：主色、56px，**一句话，越短越好**。
- 主题行：
  - 每个主题名用小括号包住，左括号在左上角、右括号在右下角。
  - 两个主题之间用一个大号主色 `&` 连接，右边的比左边低一截，形成错落。
- 灰色圆形播放按钮（视频封面才放），放在第二行标题右侧，不能压到标题。

**中间示意画面（从 y≈560 开始，一直延伸出底边）**
- 左边：浏览器窗口，旋转 -4°。
- 右边：手机，旋转 +4°，叠在浏览器右侧。
- 两个窗口上方各有一枚胶囊标签：左边黑底白字，右边主色底白字，30px。
- 一块白底黑边的提示牌，旋转 -3°，写一个核心卖点。
- 插画全部用简洁的扁平 SVG，不用照片，不用 emoji。

## 3. 内容规则

- **不编造事实**：不知道的地名、景点、功能，用灰色圆角条（骨架条）代替文字，并在回复里说明哪些是示意。
- 不画品牌 Logo、受版权保护的角色、真人肖像。工具类视频只写工具名，不画它的 Logo，也不假装还原它的真实界面。
- 视频有剪辑时，不写「全过程」「完整过程」，改用「过程实录」之类的说法。
- 文字要短，封面是给人扫一眼看的。

## 4. 出图

```bash
pip install playwright && python -m playwright install chromium   # 第一次用才需要
python scripts/render.py output/xxx.html output/xxx.png
python scripts/render.py output/xxx.html output/xxx.png --accent "#B5541E"   # 临时换主色
python scripts/render.py output/xxx.html output/xxx@2x.png --scale 2         # 高清图
```

出图后**自己先看一遍 PNG**，检查标题有没有换行、元素有没有互相遮挡、文字有没有溢出，没问题再交给用户。

如果装不了 playwright：让用户用 Chrome 打开 HTML，按 F12 打开开发者工具，在 Elements 里右键 `<div id="cover">`，选「Capture node screenshot」截图。

## 5. 标题和正文（用户需要时）

**标题**：不超过 20 字，给 3–5 个选项。能挂上节日或热点的优先挂（国庆、劳动节等）。

**正文结构**：
1. 开头一句痛点或钩子。
2. 一句话说这期讲什么。
3. 每个案例用 📍 开头，功能点用 ✅ 列出。
4. 💡 一句实用价值。
5. 引导评论。
6. 最后放 8–10 个话题标签。

写完提醒用户核对：哪些句子是推测写的，工具名是否准确。
