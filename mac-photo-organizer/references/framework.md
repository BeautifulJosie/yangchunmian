# 分类框架规则

## 结构

```
<国家>/                              ← 顶层文件夹
  <州/省>/                           ← 中间层,按需出现
    <地点> <年>.<月>                 ← 相簿
📥 未分类/                           ← skill 管理,每次重建
  无定位
  地点不明
<主题相簿>                           ← 用户自己的,不动(滑雪、婚礼…)
```

示例:

```
美国
└── 加州（California）
    ├── 太浩湖 2025.11
    └── 优胜美地国家公园 2024.11
日本                       ← 地点少,不加中间层
├── 京都（Kyoto） 2025.11
└── 大阪（Osaka） 2025.11
中国
├── 广东省
│   └── 深圳 2026.3
└── 港澳                   ← 特殊分组,用 country_aliases 实现
    └── 香港 2026.2
```

## 六条规则

### 1. 中间层按需出现

- 一个国家去过的地点超过 `region_threshold`(默认 5)个,才加州/省这一层。
- 用 `region_layer.always` / `region_layer.never` 可以强制指定。
- 已有结构优先:一个国家已经有州/省子文件夹就沿用;已经是扁平的,超过阈值也**不自动重构**,只在计划里给 warning 让用户决定。

### 2. 时间写进相簿名,不单独成层

- 默认格式 `{place} {year}.{month}`,月份不补零,如「纽约 2025.12」。要补零用 `{mm}`。
- `album_date: first` 取该地点第一张照片的年月,名字稳定,以后追加照片不用改名(默认)。`latest` 取最近一次。

### 3. 同一地点多次去

- `trip_mode: merge`(默认):一个地点一个相簿,多次去的照片都放进去。
- `trip_mode: split`:照片间隔超过 `trip_gap_days`(默认 3)天就拆成新相簿,如「东京 2024.4」「东京 2025.11」。

### 4. 地点不一定是城市

照片 App 的地理信息有几级,按顺序选地点:

1. `place_merge` 里配置的合并区域(如把 San Francisco / Oakland / San Jose 都归「旧金山湾区」)。
2. 景点/区域(Area of Interest,如 Yellowstone National Park),`prefer_area_of_interest: true` 时优先。
3. 城市。
4. 次级行政区(县)。

都没有(比如在海上)→ 进「未分类/地点不明」。

### 5. 命名与双语(写 names.yaml 时遵守)

照片 App 给的是原始地名(通常是英文,跟随系统语言)。Claude 翻译后写进 `names.yaml`:

- `bilingual: foreign_only`(默认):**本国**(`home_country`)地名只写中文;外国的州/省和地点写成「中文（English）」,如「加州（California）」「京都（Kyoto）」。
  - 例外:翻译后已经足够明确的景点可以只写中文,如「黄石」「死亡谷」,与用户已有相簿保持一致即可。
- `bilingual: none`:只写中文。`bilingual: all`:全部双语。
- 国家名始终只写中文(美国、日本)。
- 用常用简称,不用全称:「加州」而不是「加利福尼亚州」。
- 中文括号用全角「（）」。
- **已有相簿怎么叫,就怎么译。** 用户已有「太浩湖 2025.11」,则 `Lake Tahoe: 太浩湖`,不要另起名字。

### 6. 主题相簿不动

根目录的非地理相簿(滑雪、婚礼、证件、微信存图…)整个跳过。写进 `protected_albums` 的相簿,里面的照片也不参与分类(`skip_protected_photos: true`)。

## 未分类

整理相册的出发点是"去一个地方玩了,把照片归成相册"。所以只有**相机拍的照片**才参与分类;截图、网上保存的图、聊天软件存图(没有相机信息的图片)一律忽略,既不建相簿,也不进未分类。

| 子相簿 | 进来的条件 |
|---|---|
| 无定位 | 相机拍的,但没有 GPS,且前后 `infer_window_hours`(默认 6)小时内没有带定位的照片可以借 |
| 地点不明 | 有 GPS,但取不到国家或地点(海上、偏远地区) |

没有 GPS 的照片会先尝试"借定位":前后 6 小时内有带定位的照片,就跟它归到同一个地点(计划里会标出借了几张)。

## 从已有结构反推配置

首次使用时看 `scan.json` 的 `albums`:

- 顶层文件夹下有「xxx 2025.11」这类相簿 → 这是国家文件夹。
- 国家下面还有一层文件夹 → 把该国家加进 `region_layer.always`。
- 国家下直接是相簿 → 加进 `region_layer.never`(或保持阈值规则,看用户意愿)。
- 中间层的命名习惯(是否双语、「省」字带不带)→ 决定 `names.yaml` 怎么写。
- 一些地区不按行政区划分组(如「港澳」放在「中国」下)→ 用 `country_aliases`。
- 根目录下不符合「地点 年.月」格式的相簿 → 列给用户确认后加进 `protected_albums`。
- 已有相簿名 → 预先填进 `names.yaml`,保证新照片能对上旧相簿。
