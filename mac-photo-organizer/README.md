# Mac 图库整理

让 AI 帮你把 Mac「照片」App 里的旅行照片,按「国家 → 州/省 → 地点 年.月」自动整理成相簿。不用懂代码。

> v0.1:写入和撤销流程已在真实图库上验证过;按真实数据生成的分类效果还在完善,欢迎反馈。

---

## 怎么用

**不用自己下载。** 在 Mac 上打开你自己的 AI(Claude Code、Codex 这类能读写文件、能运行命令、能联网的都可以),把下面这段话整段复制发给它:

```text
请用这个工具帮我整理 Mac「照片」App 的图库:
https://github.com/BeautifulJosie/yangchunmian/tree/main/mac-photo-organizer

1. 先把这个文件夹完整下载到我电脑上,比如运行
   npx degit BeautifulJosie/yangchunmian/mac-photo-organizer ~/mac-photo-organizer
   如果用不了这条命令,可以用 git 稀疏检出,或者逐个下载里面的文件。
2. 读里面的 SKILL.md,严格按它的步骤来:你来装好需要的环境;读我的图库之前先问我;
   整理计划先给我看,我确认之后才动手。
3. 需要我在系统设置里开权限的时候,告诉我具体点哪里。
```

接下来 AI 会:

1. 下载这个工具,装好它需要的环境。
2. 请你开一次权限:「系统设置 → 隐私与安全性 → 完全磁盘访问权限」里,把你用的 AI 程序(比如 Claude)或「终端」打开。这一步只能你自己点,AI 会告诉你点哪里。
3. 读你的图库,根据你已有的相簿猜你的整理习惯,把整理计划给你看。
4. **你确认之后才动手。** 想先看看效果,可以跟它说「先试运行」。

以后有了新照片,跟 AI 说「用 mac-photo-organizer 把新照片归档」就行。

如果你用的 AI 不能联网或不能操作文件:点仓库首页的「下载这个文件夹」,解压后把整个文件夹交给它,告诉它“请照着这个文件夹里的 SKILL.md 帮我整理照片图库”。

## 整理完长什么样

```
美国
└── 加州（California）
    ├── 太浩湖 2025.11
    └── 优胜美地国家公园 2024.11
日本
├── 京都（Kyoto） 2025.11
└── 大阪（Osaka） 2025.11
📥 未分类
├── 无定位
└── 地点不明
```

- **按照片自带的拍摄时间和定位分类**。去的地方多的国家才会多一层州/省,去得少的国家直接放相簿。
- **认得你已经整理好的相簿**:新照片能对上旧相簿就追加进去,不会推倒重来;你自己手动归过类的照片不会被改回去。
- **分不出来的放进「📥 未分类」**,你自己拖进对应相簿就行。截图、网上存的图不是旅行照片,直接忽略。
- 你自己建的主题相簿(比如「滑雪」「婚礼」)不会被动。

## 放心用

- **只建相簿、往相簿里加照片**,不移动、不删除、不修改任何一张照片。
- **先给你看计划,你点头了才动手。** 还可以先「试运行」:所有相簿建在一个单独的文件夹里,你在「照片」里看一眼效果,满意再正式整理。
- **整理完不满意可以撤销。**
- 定位信息只在你自己电脑上处理,不上传。

## 想按自己的习惯改

直接跟 AI 说就行,比如:

- 「同一个地方去了好几次,帮我按每次旅行分开建相簿」
- 「相簿名改成英文」
- 「旧金山、奥克兰、圣何塞都算『旧金山湾区』」
- 「黄石放到蒙大拿州下面」
- 「『婚礼』这个相簿别动」

这些设置会保存在你电脑的 `~/.mac-photo-organizer/config.yaml` 里,下次整理还按这个来。完整规则见 [references/framework.md](references/framework.md)。

## 常见问题

**我把照片从「未分类」拖进相簿了,为什么未分类里还有?**
「照片」App 的拖拽是"添加"不是"移动"。下次整理时会自动从未分类里去掉,不用手动删。

**撤销以后还剩几个空文件夹?**
「照片」App 不支持用程序可靠地删除文件夹里的文件夹。AI 会告诉你是哪几个,你在「照片」里右键删掉就行,里面是空的。

**会上传我的照片或位置吗?**
不会,全部在你自己的电脑上完成。

## 给会用命令行的人

需要 Python 3.10+。

```bash
pip3 install -r requirements.txt
cd scripts
python3 scan.py                                         # 只读扫描图库
python3 plan.py                                         # 生成计划,预览在 ~/.mac-photo-organizer/plan.md
python3 apply.py --yes --sandbox "🧪 试运行" --limit 5   # 试运行,不碰已有相簿
python3 undo.py --yes                                   # 撤掉试运行
python3 apply.py --yes                                  # 正式整理
```

测试:`python3 -m unittest discover tests`(全部用假数据,不碰真实图库)。
