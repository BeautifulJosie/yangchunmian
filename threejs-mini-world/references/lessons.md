# 踩过的坑

做参考实现时每一个返工的原因，按「症状 → 原因 → 办法」记下来。AI 开工前可以先扫一遍。

## 风格和范围

| 症状 | 原因 | 办法 |
| --- | --- | --- |
| 用户说「平面的我不喜欢」 | 风格样张画成了 2D 插画 | 样张一律用真实 three.js 渲染，同视角同时间，只换画法 |
| 「地质层太厚，占画面太多」 | 底座做成了 5 个单位厚 | 底座薄到 1.7 左右，岛放大，素材整体缩小到约 70% |
| 岛放不下想要的东西 | 岛太小、素材太大 | 先缩素材，再放大岛；同时调水面浅滩半径 |
| 做了一堆用不上的氛围 | 一开始就铺开做多套光照 | 先做一个标准场景到定稿，再基于它衍生 |

## 渲染和场景

| 症状 | 原因 | 办法 |
| --- | --- | --- |
| 水面上有一块深色矩形 | 水下的方块顶面和水面 z-fighting | 让下面的方块顶面低于水面 |
| 沙边的薄片从水里戳出来 | 水面顶点有波动（约 3.5cm），薄片只比水面低 3cm | 薄片再低一点 |
| 阴影在岛边被切掉 | 阴影相机范围不够 | 放大阴影相机的 left/right/top/bottom |
| 物件悬空或埋进地里 | 手写 y 坐标 | 一律用 `groundHeight()` 对地形做射线查询落地；站在结构上的单独给 `lift` |
| 桥上的人悬空 | `lift` 只补了地形高度，没补桥面高度 | 对桥面单独量一次，把 `lift` 调到刚好坐在桥板上 |
| 天空渐变在俯视构图里只露一小条 | 渐变按世界 y 算，俯视看不到 | 给天空渐变加一个 `lift` 整体上移 |
| 太阳光晕不对 | 太阳圆盘的位置和光线方向不是一回事 | 圆盘位置只为画面服务，光线方向单独设 |
| 画布上的文字很丑 | 用了系统默认字体 | 用 Google Fonts，并在建场景前 `document.fonts.load` 等字体 |
| 一个看起来「太小」的物件其实是颜色问题 | 夕阳色把淡色物件洗掉了 | 对着最终光照调配色，别在中性光下定色 |

## 角色（返工最多）

| 症状 | 原因 | 办法 |
| --- | --- | --- |
| 小人头和身体像分开的 | 三个独立几何体叠在一起 | 用连续的身体，头直接坐在身上，不要脖子 |
| 骑自行车的人穿模 | 木偶没有腿，坐不到车座上 | 改成「推着车走」，人和车做成一个组件 |
| 滑板、冲浪板上的人穿模 | 脚直接插进板里 | 人抬高到板面上，给一对短腿 |
| 拿东西的手里什么都看不见 | 道具放在了身体里面 | 道具放到身体前方，手臂抬起来托着；大小放大一些 |
| 冲浪板像一个圆筒 | 胶囊体压扁后从侧面看是圆的 | 用椭球压成扁平的尖头板，竖着夹在腋下，换到背对镜头的那只手 |
| 站着不动「没有故事」 | 只有人，没有道具和动作 | 每个角色一件道具 + 一个动作 |
| 吉他斜插进身体 | 旋转轴不对 | 音箱的圆面要垂直于地面、正对前方，抱在胸前 |
| 角色放回岛上后穿模 | 一起摆的时候没分区 | 按区域摆（海滩一排、马路边、草坪、码头），放完逐个近景检查 |
| 躺椅上的人头朝向很怪 | 没有对齐躺椅的靠背 | 头朝靠背那头，脚朝椅尾，身体贴在椅面上 |
| 情侣放在桥下面 | 位置和桥重叠 | 移到桥边沙滩，不和任何结构重叠 |

## 无头渲染

| 症状 | 原因 | 办法 |
| --- | --- | --- |
| 脚本报 `ERR_CONNECTION_REFUSED` | dev server 在对话间隔被回收 | 重新用 `nohup npx vite --port 5173 --strictPort &` 后台启动，等几秒再截图 |
| Playwright 找不到浏览器 | 没装或版本不匹配 | `npx playwright install chromium`，或设置 `CHROMIUM_PATH` |
| 截图一片空白 | 页面还没初始化完 | 等 `window.__island` 出现再渲染 |
| 细节镜头只拍到半个物件 | 取景距离不对 | 以目标物件的世界坐标为中心，按物件大小算相机偏移，每张都要看过 |
| 想批量看一排角色但互相遮挡 | 一张图塞太多 | 每个角色单独渲染，再用 PIL 拼成联系表 |

## 音乐

| 症状 | 原因 | 办法 |
| --- | --- | --- |
| 播放一分钟后某一小节突然变响 | 滚动排曲时用时间差取整，重复排了一小节 | 用单一小节游标往前排，`scheduleAhead(until)` |
| 页面一打开就没声音 | 浏览器要求先有用户手势 | 「点击进入」遮罩 + 在点击里创建 `AudioContext` |
| 想让用户先听再决定 | 在线播放没法发给用户 | 用 `OfflineAudioContext` 渲染成 WAV，先发文件试听 |
| 无法判断好不好听 | AI 听不到 | 只检查没报错、没削波，如实告诉用户「好不好听要你来判断」 |

## 小红书海报

| 症状 | 原因 | 办法 |
| --- | --- | --- |
| 总览图里小飞机的横幅挡住海滩 | 动画时间正好飞到这里 | 推进时间直到飞机在画面右前方的海面上再截图 |
| 细节图是一片紫色天空 | 相机对准了建筑中心，建筑在画面下沿 | 以建筑的世界坐标为基准，相机朝向略往下 |
| 中文手写体字很大 | Ma Shan Zheng 一个字重 5MB+ | 用 Google Fonts 在线引用，不要提交字体文件 |
| 海报文字被图盖住 | 绝对定位的图和文字叠在一起 | 排版后看一遍成图，再微调坐标 |
